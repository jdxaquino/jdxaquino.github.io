# jdxaquino.github.io

Página personal (perfil de formación y experiencia), publicada con GitHub Pages.

- **Contenido:** un solo `index.html` sin dependencias externas (HTML, CSS y JS en línea).
- **Idioma:** botón ES/EN. Cada texto existe en ambos idiomas como `<span data-l="es">` y `<span data-l="en">`; al editar, actualiza los dos.
- **Tema:** botón claro/oscuro. Por defecto sigue la preferencia del sistema; la elección se guarda en `localStorage`.
- **Pendientes:** busca `REVISAR` en `index.html` (nombre, LinkedIn, correo, instituciones y años, descripción del notebook de Colab).
- **Publicación:** *Settings → Pages → Deploy from a branch*, rama `main`, carpeta `/ (root)`.
